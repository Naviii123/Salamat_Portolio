# Ivan Louis D. Salamat — Portfolio

Personal portfolio for **Ivan Louis D. Salamat**, a Computer Science student at Holy Angel University. The site introduces my background, technical skills, academic achievements, selected credentials, and project work.

## Portfolio contents

- About and professional summary
- Technical skills
- Personal and collaborative projects, including PanelTracker, ViVy, and Shifted
- Education and academic achievements
- Certifications with links to their credentials
- Contact information

## Built with

- React
- Vite
- JavaScript
- CSS

## Run locally

From the repository root:

```bash
cd portfolio
npm install
npm run dev
```

Create and preview a production build:

```bash
npm run build
npm run preview
```
